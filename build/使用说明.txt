本地截图翻译 v1.5.0  使用说明
================================

【启动】
  双击 LocalTranslator.exe
  首次启动会自动加载模型（约 8-10 秒），右上角状态变为「服务就绪」。

【界面】
  左侧导航切换两个页面：「截图翻译」与「文本翻译」。
  「截图翻译」页有两个按钮：框选翻译（Alt+Q）与实时翻译（Alt+R），
  右侧显示推理服务状态。所有结果都在窗口或浮窗内显示，不弹系统对话框。

【功能一：框选翻译（单次）】
  1. 按 Alt+Q 或点「框选翻译」
  2. 屏幕定格变暗，拖拽框出要翻译的区域
  3. 译文显示在右侧详情区，历史记录在左侧列表
  4. 点「复制译文」复制当前结果

【功能二：实时翻译】
  1. 按 Alt+R 或点「实时翻译」
  2. 拖拽框出一块区域（视频字幕、聊天窗口、滚动文档等）
  3. 框选结束后主界面隐藏，弹出独立的半透明浮窗显示译文；
     区域内文字变化时自动重新翻译
     浮窗内分两块：上面灰色小字是「上一段」译文（保留到你下一段出现），
     下面是当前最新译文
  4. 浮窗右上角「⚙」齿轮里可调节：
       · 字号        − 17 +        12–32
       · 透明度      滑块          25%–95%
     （这两项会记住，下次沿用；再点齿轮或点别处收起）
  5. 拖动浮窗标题栏可移动；拖右下角可自由调整大小（最小 340×200，尺寸会记住）；
     关闭方式：点 ×、Esc、或 Alt+W
  6. 检测机制：每 300ms 抓一次；画面一变化就识别（最快 0.5s 一次，自动限速）；
     画面静止时每 1.2s 兜底识别一次。视频/字幕这类持续变化的画面同样能跟上。

【功能三：文本翻译】
  切到「文本翻译」，粘贴或输入文字，按 Ctrl+Enter
  译文显示在下方，可一键复制。适合单词、句子、整段。

【快捷键】
  Alt+Q        框选翻译（单次）；实时翻译进行中也可以按，
               此时实时会暂停，单次翻译完成后自动继续
  Alt+R        开始实时翻译（实时中再按 = 关闭实时）
  Alt+P        暂停 / 继续实时翻译（暂停期间不抓屏、不翻译，画面与译文保持不动）
  Alt+W        退出实时翻译
  Esc          取消框选 / 关闭实时浮窗
  Ctrl+Enter   文本翻译

【目标语言】
  支持六种语言互译：中文、英文、日语、俄语、西班牙语、法语。
  「自动判断」：源语种自动识别，中文→英文，其它语种→中文。
  也可手动锁定目标语种（源语种始终自动识别）。
  中/英/日/西/法 共用一套 OCR 模型；俄语会自动切换到西里尔模型。

【设置记忆】
  以下设置在变更时自动保存，下次启动原样恢复：
    目标语言、浮窗字号、浮窗透明度、浮窗大小、窗口位置与大小、当前页面
  保存位置：程序目录下的 settings.json（便携，可手工编辑）
  恢复默认：删掉 settings.json 再启动即可。

【换模型】
  把新的 .gguf 放进 models\ 目录即可（同名覆盖，或删掉旧的）。
  程序会选「修改时间最新」的那个 .gguf，换完重启即可。
  注意：必须是 Hunyuan v1 dense 架构的 GGUF；换成其它家族模型需要改代码。
  也可用环境变量 LT_MODEL 指定具体文件。

【自检】
  LocalTranslator.exe --selftest
  打印环境/服务/OCR/翻译检查结果，并生成 selftest_report.txt。

【目录说明】
  LocalTranslator.exe   主程序
  settings.json         设置（首次运行后生成）
  _internal\            Python 运行时、PySide6、Fluent、onnxruntime、OCR 模型
  runtime\              llama-server.exe 与 CUDA 运行库
  models\               翻译模型（*.gguf）

【环境要求】
  Windows 10/11 x64（浮窗截屏排除需要 Win10 2004+）
  NVIDIA 显卡（当前构建 CUDA 13.4），显存建议 ≥6GB
  纯本地运行，不联网；端口固定 127.0.0.1:8080

【第三方组件许可】
  界面使用 PySide6-Fluent-Widgets（qfluentwidgets），许可为 GPLv3。
  自用无影响；对外分发本程序需遵循 GPLv3（开源本程序）或购买商业授权。
  OCR 使用 RapidOCR（Apache-2.0），推理使用 llama.cpp（MIT），模型权重遵循其原始许可。

【常见问题】
  1. 提示「推理服务不可用」：多为显存不足，关掉其它占显存的程序后重试。
  2. Alt+Q / Alt+R / Alt+W 无反应：安全软件拦截键盘钩子，用界面按钮即可。
  3. 实时浮窗挡住内容：拖标题栏移开，或调高透明度。
  4. 实时翻译偶尔滞后：每次变化需要 OCR（~0.3s）+ 翻译（~0.2-0.6s），
     画面快速滚动时会有约 1 秒延迟，属正常。
  5. 识别不准：尽量框得贴合文字；小字号（<10px）和浅灰字容易丢。
